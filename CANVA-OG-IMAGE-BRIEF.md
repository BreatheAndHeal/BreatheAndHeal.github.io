# Canva brief — The Unsaid Open Graph share image

## Canvas
- Size: **1200 × 630 px** (landscape, 1.91:1)
- Export: **JPG**, sRGB, target file size under **300 KB**
- Filename when added to the site: **og-image.jpg** at the repository root

## Brand direction
- Background: flat warm cream **#f4efe6**. No marble, paper texture, mockups, gradients, drop shadows, browser frames or watermark.
- Main asset: use the provided clean transparent logo-full SVG/PNG. Keep its original proportions and its deep forest-green line art. Do not redraw, stretch or add a different mark.
- Text tagline, exactly: **“For everything you never knew how to say.”**
- Typography: restrained, editorial, calm; use the site's current Playfair Display style for the tagline if available, otherwise use a similar classic high-contrast serif. Keep the logo wordmark as artwork and avoid retyping it.
- Colour: keep the logo and tagline deep forest green close to **#173D35**. Avoid extra colours.

## Layout
1. Place the full logo horizontally/vertically centered as the primary element, leaving generous breathing room.
2. Place the tagline below the logo, centered, on one or two lines. Make it large enough to read in a social preview without competing with the logo.
3. Maintain safe margins of at least 70 px on all sides. Do not crop the hands, star, wordmark or “GUIDANCE & REFLECTION” tagline in the logo artwork.
4. No additional claims, prices, URLs, contact details, people or stock imagery.

## Export checklist
- 1200 × 630 px exactly.
- Cream background **#f4efe6**; crisp deep-green logo; exact sentence punctuation.
- Export as JPG and compress so the file is **under 300 KB**.
- Save as **og-image.jpg** and add it to the repository root so https://theunsaidcare.com/og-image.jpg resolves.

## Current limitation
The homepage, journal and guide metadata already point to /og-image.jpg; until the exported JPG is added to the deployed repository, share previews may show a missing image. No analytics snippet has been added because the site-specific Cloudflare Web Analytics snippet has not yet been supplied.
